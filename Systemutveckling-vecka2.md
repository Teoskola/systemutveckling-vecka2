Frågor 
1. Beskriv skillnaden mellan vattenfallsmodellen och agil metodik.

Vattenfallsmodellen är en arbetsmetod där du sätter upp en konkret detaljerad plan från början av projektet
och sedan följer den ett steg i taget. Bra för projekt med konkreta krav och mål.
Agil metodik är när man jobbar i perioder så att man periodvis kan testa och samla feedback om projektet
så att du kan anpassa det efter varje steg. Denna arbetsmetod är bäst att använda när kraven för projektet
inte är helt konkreta och kan ändras eller om du jobbar nära med andra personer för att undvika fel.

2. Vad är ett Git-commit och varför är det viktigt?
Git commit är när du sparar en ändring i en branch på github.
Commit är viktigt för att det också dokumenterar din kod så att du kan gå tillbaka och kolla på vad du har skrivit tidigare.
Till exempel om jag har gjort ett fel i en branch och inte vet hur jag kan fixa det så kan jag gå tillbaka och kolla
på tidigare kod eller ersätta en branch med en tidigare commit.

3. Vad innebär samarbete med GitHub? Vad är pull requests, branches och merge?
Ett samarbete i Github är när flera personer arbetar i samma repo (en mapp där du sparar filer till ett projekt).
När du arbetar i ett repository på Github så kan du skapa olika grenar alltså branches av projektet.
När du ändrar något i en branch så påverkar det inte huvudgrenen (main) tills du mergar grenarna alltså lägger
ihop branches. Du kan merga branches genom att skicka ett pull request alltså en förfrågan om att lägga ihop grenar
som vanligtvis någon annan i projektet måste svara på för gör en merge.
